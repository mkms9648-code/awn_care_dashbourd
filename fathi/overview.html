تحت الإنشاء

لوحة فتحي هتشتغل على مشروع Supabase منفصل، ومحتاجة أول حاجة نبني ليها طبقة أدمن (app_admins + دوال admin_*) زي عون كير بالظبط. بعدها هتلاقي هنا:

  متابعة الشات بين كل عميل وفتحي (نفس شاشة عون كير)
  تشغيل/إيقاف كل وحدة لكل عميل (شات، مخزون، مناديب، عمليات…)
  إدارة كود دخول كل شركة: إنشاء / تغيير / إلغاء
  إنشاء عملاء جدد وتفعيلهم/إيقافهم
