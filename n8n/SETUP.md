# مساعد المبيعات — إعداد n8n (نص + قراءة صور)

المساعد بيشتغل عن طريق **n8n**. اللوحة بتبعت السؤال (ومعاه صورة اختيارية) لـ webhook،
والـ webhook بيقرا "المعرفة" من Supabase، يسأل **Gemini**، ويرجّع الرد.

## عقد الاتصال (Contract)

**الطلب** (POST JSON من اللوحة):
```json
{
  "product": "awncare | fathi",
  "message": "سؤال الموظف",
  "session_id": "…",
  "history": [ {"role":"user|assistant","content":"…"} ],
  "image": "data:image/png;base64,....",   // اختياري (سكرين شوت)
  "image_mime": "image/png"                 // اختياري
}
```
**الرد** المتوقع: `{ "reply": "رد المساعد" }` (اللوحة بتقبل كمان `output`/`text`/`answer`).

## الخطوات (القالب الجديد بيقرا الصور)

1. **استورد** `sales-assistant.json` (Import from File). الفلو:
   `Webhook → Get KB → Build Gemini Request (Code) → Gemini (HTTP) → Respond`.
2. **مفتاح Gemini**: افتح نود **Gemini** وغيّر `YOUR_GEMINI_API_KEY` في آخر الـ URL
   بمفتاح Google AI Studio بتاعك (نفس المفتاح اللي ورا كريدنشال Gemini في فلوزك).
   تقدر تغيّر الموديل كمان (مثلاً `gemini-2.0-flash` أو `gemini-1.5-pro`).
3. **Get KB**: بيقرا من دالة `sales_kb_get` على مشروع عون كير (المفتاح anon متحطوط).
   لازم تكون شغّلت `sql/026_sales_assistant.sql` الأول.
4. **فعّل** الـ workflow، وخُد الـ **Production URL** (المفروض نفسه:
   `.../webhook/sales-assistant`) — وهو أصلاً متحط في `config.js`.
5. من اللوحة → مساعد المبيعات → **تعديل المعرفة** → املأ الشخصية + الأسعار/الباقات/
   الدفع/اللينكات، واحفظ.

## قراءة السكرين شوت
- الموظف بيضغط زرار الصورة 📷 في الشات، يختار سكرين شوت (مثلاً محادثة واتساب مع عميل)،
  ويكتب "رد عليه إزاي؟" ويبعت. الصورة بتتبعت base64 جوه نفس الطلب.
- نود **Build Gemini Request** بيحط الصورة كـ `inline_data` مع آخر رسالة، وGemini
  بيقراها. الحد الأقصى للصورة من اللوحة 5 ميجا.

## زرار النسخ
تحت كل رد من الـ AI فيه زرار 📋 بينسخ نص الرد — شغّال تلقائيًا، مش محتاج أي إعداد.

## أمان وملاحظات
- المفتاح في الـ URL بيفضل داخل n8n بس (مش في المتصفح) — آمن.
- ممكن تحمي الـ webhook بـ Header Auth في n8n لو حبيت تمنع أي استدعاء خارجي.
- `sales_kb_get` بترجّع معلومات المبيعات بس (مش سرية).
